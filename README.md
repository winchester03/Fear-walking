# Fear Walking 0.3.3

Built from the stable 0.3.2 forest version.

## Controls
- Tap the ground to walk there.
- Drag anywhere to look around.
- While walking, hold the screen without dragging to run.
- Tap CROUCH to crouch; tap again to stand.
- Hold CROUCH to go prone; press it again to stand.

## Lighting
- Five-minute accelerated day/night cycle beginning in daytime.
- Moving sun and moon.
- Dynamic sky colors through daytime, sunset, night, dawn, and sunrise.
- Cascaded real-time shadows and screen-space volumetric sunlight shafts.

Hardware ray tracing is not supported by this mobile Babylon.js web build. The build uses dynamic shadow maps, light occlusion, and volumetric scattering to produce the closest practical effect.
